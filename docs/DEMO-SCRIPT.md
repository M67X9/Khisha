# Screen recording script (about 3 minutes)

Goal: show the app from the user's side, from start to finish. Record on your iPhone (Control Centre > Screen Recording) while running Khisha in Expo Go. Use fake documents only while the AI runs on free models.

## Before recording
1. Make two fake files: a receipt screenshot (store name, a date, a total such as 18.450 KWD) and, if you like, an Arabic receipt.
2. Use a fresh account so the first-time experience is shown. Use a name you are happy to show.
3. Turn on Do Not Disturb. Keep the phone on Wi-Fi and the app in English first.
4. Optional: add a voice-over saying what you tap.

## Shots
| Time | What to show | What to say |
|---|---|---|
| 0:00 | Sign-up screen. Enter name, gender (show the colours change), email, password. | "Khisha is a personal AI memory assistant." |
| 0:20 | Home greeting with your name. Point at Search, Ask AI, Add. | "It greets me by name and keeps everything in one place." |
| 0:35 | Add Memory > choose the receipt screenshot > Upload. Show the "reading" screen. | "I upload a receipt. The AI reads it on the server." |
| 1:00 | Review screen: file preview on top, fields below. Change the total on purpose, then tap Confirm on total and date. Show Save disabled before confirming. | "Nothing is saved until I confirm each important number. I can correct it." |
| 1:30 | Switch Keep original on, tap Confirm and save. Show the memory detail with the Confirmed tags. | "I choose whether to keep the original file." |
| 1:50 | Home: the new memory in the list and category counts. | |
| 2:00 | Search: type a word from the receipt, then try a typo. Tap a category chip. | "Search works across Arabic and English and forgives typos." |
| 2:20 | Ask AI: ask "How much was my receipt from [store]?" Show the answer and tap the source card. | "Answers come only from my memories, with the source." |
| 2:40 | Ask something not saved (for example "How much was my parking ticket?"). | "If it is not in my memories, it says so instead of guessing." |
| 2:50 | Settings > switch to Arabic. Show the mirrored Home. | "Arabic is a true right-to-left layout." |
| 3:00 | End on Home. | "That is Khisha: save it now, find it later." |

## Tips
- Do one practice take. The AI reading takes 10 to 30 seconds on free models; trim the waiting in any editor, or say a line while it loads.
- If a free model is busy, tap Try again.
- Keep the recording under the length your submission allows, and check the file size limit before uploading.
